# ADR 0006: сборка мода в браузере — страница на GitHub Pages

## Статус
Предложено (реализация отложена)

## Дата
2026-11-10

## Контекст
Собрать мод сейчас можно только на ПК: `extract.py` + `build_mod.py` (Python 3, Pillow, numpy) или
собранный сборщик (I2, I3) для Windows, Linux и macOS. Игроки на Android-порте (issue #1) собирают
на ПК и переносят папки на телефон. Готовый мод раздавать нельзя: в нём изменённые файлы игры.

Ограничения со стороны порта (docs/MODS.md порта, v0.44.0):
- сторонние импортёры (F1 > Mods > Run) — только на ПК, на Android сборщик внутри порта не
  запустить;
- импорт Remastered на Android лежит во внутренней памяти приложения, другим программам он
  недоступен.

Сборщик — чистый Python: stdlib, Pillow, numpy. Образ читается файловым объектом (`open`, `seek`,
`read`), из ~1,4 ГБ читаются только нужные PAK.

## Решение
- Статическая страница на GitHub Pages этого репозитория
  (`454135431515.github.io/Metroid-Prime-RU/`): игрок выбирает свой ISO и получает zip с `russian` и
  `hud-russian`. Сборка идёт целиком на устройстве, образ никуда не загружается, сервера нет.
- Внутри — тот же `tools/` без переписывания, в Pyodide (CPython в WebAssembly, Pillow и numpy в его
  составе), в Web Worker. Образ монтируется как WORKERFS: читается кусками по запросу, в память
  целиком не копируется.
- Pyodide и пакеты лежат на той же странице Pages, не тянутся с чужого CDN.
- Страница собирается и публикуется CI при слиянии в `main`, как сборщик в I3. На Pages — только код
  и перевод (то, что уже в репозитории), данных Nintendo нет.
- Remastered (HD-шрифт) страница не собирает: импорт Remastered официально не поддерживается
  (README), а на Android он ещё и недоступен.
- Готово, когда zip со страницы побайтно равен сборке `build_mod.py` на ПК из того же образа.

## Рассмотренные альтернативы
### Приложение для Android (APK со встроенным Python)
- За: работает без браузера.
- Против: только Android; сборка APK, подпись, доступ к файлам через SAF, отдельный CI; результат
  тот же, что у страницы.
- Отклонено.

### Termux (терминал для Android) и команды из README
- За: ноль кода, только инструкция.
- Против: командная строка и выдача доступа к файлам — не для обычного игрока; на телефоне не
  проверено.
- Отклонено как основной путь; годится временной инструкцией для тех, кто готов к терминалу.

### Сборщик внутри порта на Android
- Против: порт запускает импортёры только на ПК; зависит от чужого проекта.
- Отклонено.

## Последствия
- Неизвестно до прототипа: память и время сборки на телефоне. Если телефон не тянет — остановка и
  пересмотр этого ADR.
- Pages включает владелец (Settings → Pages → Source: GitHub Actions), перед первой публикацией.
- `tools/` должен остаться чистым Python без внешних программ и собственных C-расширений: иначе он
  не запустится в браузере.
- Pyodide (~10–15 МБ) скачивается один раз и кешируется браузером.
