# ADR 0007: нарисованные вручную буквы в растровых шрифтах диска

## Статус
Принято (дополняет ADR 0002)

## Дата
2026-11-10

## Контекст
По ADR 0002 кириллица растровых шрифтов Deface строится рецептами: копии латиницы и цифр, зеркала,
генератор из прямоугольников. Рецепт «копия» сделал Ч точной копией 4, З — копией 3 (ч и з — их
уменьшенные копии): в тексте буквы не отличить от цифр. Во второй части (Echoes) это решено
нарисованными вручную пиксельными буквами, владелец выбрал вариант 2. Для первой части дизайн нарисовал
Ч З ч з в том же варианте под латиницу каждого из пяти шрифтов; владелец принял 2026-11-10.
Перенести буквы Echoes нельзя: шрифты одного семейства, но латиница отличается в 13–17 буквах.

## Решение
- Нарисованные буквы лежат в `tools/pixel/<имя шрифта>.txt` (имя из FONT: `Deface13B`, …): блоки
  `U+XXXX Ч`, затем строки `#`/`.`, без пустых столбцов по бокам. Блок — только заливка, ровно высота
  буквы, низ блока на базовой линии.
- `cyrillic.add_glyphs`: если буква есть в файле своего шрифта, маска берётся оттуда, рецепт не
  действует. Ячейка, отступы, baseline и контур (для `Deface14B_O`) — как у прочих нарисованных глифов
  (`place`): по образцу метрик рецепта (Ч — 4, З — 3, ч и з — n). Высота блока обязана совпасть с
  высотой образца, иначе сборка падает с ошибкой.
- Остальные буквы — по рецептам ADR 0002, как раньше.
- Папка входит в собранный импортёр (`freeze.sh`), как `tools/glyphs` для HD-шрифта.

## Рассмотренные альтернативы
### Исправить рецепты (генератор Ч и З)
- Против: правки рецептов владелец отклонял (T4h, T4i, ADR 0004); форма утверждается рисунком,
  а не кодом.
- Отклонено.

### Все буквы рисовать вручную сразу
- Против: остальные буквы владельца устраивают; лишняя работа и риск.
- Отклонено, файлы позволяют дорисовывать по одной.

## Последствия
- Форма нарисованной буквы правится в txt, а не в коде.
- Латиница по-прежнему побайтно прежняя (тест генератора).
- Файлы — часть кода (MIT, как `tools/`).
