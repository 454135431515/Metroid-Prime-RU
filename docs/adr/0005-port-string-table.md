# ADR 0005: строки порта — своя таблица STRG 504F5254 в моде

## Статус
Принято

## Дата
2026-11-10

## Контекст
Порт рисовал свои строки в игровых экранах (Exit Game, пункты паузы, легенда карты, Mark room,
Warp to start) из кода, и мод не мог их перевести (SPEC A7; issue Odrannnn/MetroidPrimePort#280 по
нашей просьбе). С v0.44.0 они читаются из таблицы STRG `504F5254`, которой нет ни на одном диске:
мод кладёт `504F5254.STRG` рядом со своими таблицами (docs/MODS.md порта, «Translating the port's own
text»). Строки не меняют индекс между версиями, новые добавляются в конец; строки, которой нет в
таблице мода, остаётся английской. Таблица не входит ни в один PAK, поэтому ограничение T7f («мод не
добавляет новых id в PAK») её не касается.

## Решение
- Перевод строк порта — `text/port.json`: `{индекс: {en, ru}}`, `en` — английский порта той версии, с
  которой переводили (v0.44.0). `build_mod.py` собирает из него `504F5254.STRG` (версия 0, одна секция
  ENGL, как таблицы диска) в мод `russian`.
- Индексы в `port.json` идут подряд с 0; дыра — ошибка сборки.
- Новые строки новой версии порта: дописать в `port.json` по таблице из docs/MODS.md порта; до этого
  они видны по-английски (поведение порта, не ошибка).

## Рассмотренные альтернативы
### Строки порта в `ru.json`
- Против: ключ `ru.json` — id таблицы диска и хеш английского с диска; у таблицы порта нет диска,
  английский берётся из документации порта.
- Отклонено.

## Последствия
- Легенда карты (индексы 4–8): до 9 знаков на пункт и 15 на пару (ограничение порта).
- Пункты паузы (индексы с 9) — не шире самой длинной английской строки порта в каждом шрифте мода
  (Arm Cannon Follows FOV): под неё порт рассчитан. Проверяет `test_build_mod`; «Toggle X» поэтому —
  «X нажатием».
- При обновлении порта сверить таблицу в docs/MODS.md с `port.json` (тикет P-port).
