# ADR 0004: нарисованная вручную кириллица в HD-шрифте

## Статус
Принято

## Дата
2026-11-09

## Контекст
Кириллица HD-шрифта (`tools/hd_font.py`) собиралась теми же рецептами, что растровая
(`tools/cyrillic.py`): копии латиницы, зеркала, конструкторы из прямоугольников. Для простых букв
этого хватает, но сложные формы (Ч, Л, З, Ж, Д) выходили механическими; правки рецептов (T4h, T4i)
владелец отклонил. HD-шрифт порта и игровой шрифт Remastered — один и тот же шрифт (метрики совпали),
так что одни нарисованные буквы годятся для обоих.

## Решение
- Буквы, которых нет в латинице, рисуются вручную по заданию (сетка, стиль, пропорции латиницы) и
  лежат в `tools/glyphs/U+XXXX.svg`. Сетка: `viewBox="0 0 <ширина> 1200"`, базовая линия y=900,
  верх заглавных y=200, верх строчных y=336, низ выносных y=1137; только контуры M/L/Z, дыры —
  evenodd; без отступов по бокам.
- `hd_font.make_glyphs`: если для буквы есть SVG, маска берётся из него (высота заглавной 700 единиц =
  высота H в пикселях маски, сглаживание 4×4), иначе — рецепт. Отступы и ширина — по латинскому
  образцу рецепта, как раньше.
- Растровые шрифты диска (GameCube) остаются на рецептах: буквы там 10–20 пикселей, вектор при таком
  уменьшении размывается.
- metroid-prime-remastered-ru получает папку копией (`tools/sync_gc.py`), как остальной код шрифтов.

## Последствия
- Форма буквы правится в SVG, а не в коде; рецепты HD для нарисованных букв больше не действуют.
- Буквы, совпадающие с латиницей (А В Е К Н О Р С Т Х, а е о р с у х), по-прежнему копии.
- SVG — часть кода (лицензия MIT, как `tools/`).
