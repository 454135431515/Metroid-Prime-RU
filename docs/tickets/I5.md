# I5: сборка мода в браузере (Android без ПК)

Ветка: `i5-web` · Статус: done · Размер: M
Зависит от: I4, ADR 0006

## Цель
Игрок на Android (issue #1) открывает страницу, выбирает свой образ и получает рабочий мод без ПК.

## Критерии приёмки
- [x] `web/`: страница и worker; сборка в Pyodide тем же кодом, что импортёр (`importer.build_mods`)
- [x] zip со страницы побайтно равен сборке `build_mod.py` (все 1322 файла)
- [x] CI публикует страницу на GitHub Pages с Pyodide на самой странице (`pages.yml`)

## Проверка
- [x] `tools/test.sh` зелёный
- [x] `node web/check.mjs <сайт> <образ> <zip>`: Pyodide под Node, 16 с; файлы равны эталону
- [x] страница в браузере (локальный сервер): сборка 12 с, архив 1322 записи; чужой образ (PAL) —
      понятная ошибка; вид на ширине телефона
- [ ] на телефоне владельца после публикации

## Файлы
- `web/index.html`, `web/worker.js`, `web/assemble.sh`, `web/check.mjs`, `tools/web_build.py`,
  `tools/importer.py`, `.github/workflows/pages.yml`, README, ADR 0006
