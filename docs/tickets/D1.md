# D1: Ч и З не похожи на 4 и 3

Ветка: `d1-ch-ze` · Статус: done · Размер: S
Зависит от: T4a

## Цель
Ч З ч з в пяти растровых шрифтах не путаются с цифрами 4 и 3.

## Критерии приёмки
- [x] нарисованные Ч З ч з (вариант 2, как во второй части) в `tools/pixel/` для всех пяти шрифтов
- [x] сборка берёт их вместо рецептов (ADR 0007); латиница побайтно прежняя
- [x] буквы приняты владельцем по превью дизайна (2026-11-10)

## Проверка
- [x] `tools/test.sh` зелёный (`test_cyrillic`: ячейка = маска из файла, Ч ≠ 4, З ≠ 3)
- [x] `docs/screenshots/d1-ch-ze.png` — сообщение HUD в игре, порт v0.44.0

## Файлы
- `tools/pixel/*.txt`, `tools/cyrillic.py`, `tools/test_cyrillic.py`, `tools/freeze.sh`

## Итог
Рецепт «копия» делал Ч точной копией 4, З — копией 3. Теперь эти буквы рисуются вручную, как во
второй части; буквы второй части не перенести — латиница Deface там отличается в 13–17 знаках.
HD-шрифт не менялся: там Ч и З уже нарисованы (ADR 0004).
