# I2: импортёр одним исполняемым файлом

Ветка: `i2-freeze` · Статус: in progress · Размер: S
Зависит от: I1

## Цель
Игроку не нужен Python: `russian` (Linux) / `russian.exe` (Windows) кладётся в `user/importers`.

## Решение
`tools/freeze.sh`: PyInstaller `--onefile`, внутри Python, Pillow, numpy, `text/ru.json`,
`text/panes.json`, `tools/glyphs/` (SVG-буквы HD-шрифта). Собирает под ту ОС, где запущен.

## Критерии приёмки
- [x] Linux: 35 МБ, через `--import russian` порта мод побайтно равен рабочему, 10 с
- [ ] Windows-версия (I3, GitHub Actions)
- [ ] Linux-версия на старом glibc: собранная здесь требует glibc 2.44 (CachyOS) — собирать в CI
      на старой системе (I3)
