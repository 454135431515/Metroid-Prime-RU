# I3: импортёр под все ОС порта в CI

Ветка: `i3-ci` · Статус: done · Размер: S
Зависит от: I2

## Цель
Готовый импортёр для каждой ПК-сборки порта: Linux x86_64, Windows x86_64, macOS arm64. Собранный
здесь (CachyOS) требует glibc 2.44 и на большинстве Linux не стартует.

## Решение
`.github/workflows/importer.yml`: `tools/freeze.sh` на ubuntu-22.04 (glibc 2.35), windows-latest,
macos-latest (arm64; образ macos-14 GitHub снял); проверка запуска (без порта — код 1 и сообщение про `MP_MODS_DIR`); архивы
`russian-importer-<ос>.tar.gz|zip` — артефакты, а по тегу `v*` — в релиз. Вывод импортёра — UTF-8
(в pipe Windows Python писал бы в cp1252).

## Критерии приёмки
- [ ] workflow зелёный на трёх ОС (ручной запуск)
- [ ] Linux-архив из CI: `--import russian` портом v0.43.0 здесь, мод побайтно равен Python-сборке
- [ ] Windows, macOS: проверка запуска в CI; полный импорт там не проверен (нет машин)
- [ ] README: установка без Python
