# T4k: нарисованная кириллица в HD-шрифте

Ветка: `t4k-svg-glyphs` · Статус: done · Размер: M
Зависит от: T4j

## Цель
Русские буквы HD-шрифта (порт с импортом Remastered и PrimeRecomp) выглядят как родные: нарисованы
вручную в стиле латиницы шрифта, а не собраны рецептами.

## Решение
ADR 0004: 49 SVG в `tools/glyphs/` (23 заглавных, 26 строчных; совпадающие с латиницей — копии),
импорт в `tools/hd_font.py` (`svg_glyphs`, `svg_drawn`). Растровые шрифты не меняются.

## Критерии приёмки
- [x] все 49 SVG читаются, `tools/test.sh`: 0 ошибок
- [x] Ч, З, Э, б перерисованы (крупнее скругление чаши Ч, короче перекладина З, дуга Э, выносной
      у б); различие с 4 и 3 в игре небольшое — владелец принял как есть
- [x] в игре: PrimeRecomp (владелец), проверочная строка на титульном экране
