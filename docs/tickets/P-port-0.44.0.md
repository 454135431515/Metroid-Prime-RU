# P-port-0.44.0: порт v0.44.0, перевод строк порта

Ветка: `p-port-0.44.0` · Статус: done · Размер: S
Зависит от: P-port-0.43.0

## Цель
Мод работает на порте v0.44.0, а строки самого порта (Exit Game, пункты паузы, легенда карты, Mark
room, Warp to start) по-русски — порт сделал их переводимыми по нашей просьбе (#280).

## Критерии приёмки
- [x] ADR 0005; `text/port.json` (48 строк) → `504F5254.STRG` в моде; тест
- [x] лог порта: `text: the port's strings come from a mod (48 of 48)`; «Выйти из игры» в главном меню
- [x] пункты паузы и легенда карты: ширина каждого пункта не больше самой длинной английской строки
      порта во всех шрифтах мода, легенда — по ограничениям порта (`test_build_mod`); глазами в игре —
      владелец при игре (скриптом пауза из консоли не открывается)
- [x] прогон 276 комнат с Remastered и без: 0 вылетов, 0 ошибок ресурсов; `83F6FF6F/3C785450` — пустая
      ошибка warp, как на 0.43.0; ADR 0001 и README — версия 0.44.0
