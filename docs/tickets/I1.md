# I1: сборщик перевода как импортёр порта

Ветка: `i1-importer` · Статус: done · Размер: S
Зависит от: T5

## Цель
Мод собирается кнопкой Run в F1 > Mods порта (Custom importers, docs/MODS.md порта), без команд.

## Решение
`tools/importer.py`: папка модов из `MP_MODS_DIR`; диск — аргумент, затем `disc_path` из
`port_settings.ini` (порт запоминает выбранный образ), затем единственный `.iso` рядом; проверка
заголовка GM8E01 rev 0; extract во временную папку, build_mod в `<mods>/russian` (HD-шрифт —
если рядом `remastered-models`). Ошибка — текст и код 1.

## Критерии приёмки
- [x] `--import russian <iso>` портом v0.34.0, повторно v0.43.0: мод побайтно равен рабочему, с HD-шрифтом
- [x] диск из `disc_path`; чужой образ и запуск не из порта — понятная ошибка (`test_importer`)
- [x] один исполняемый файл без Python (I2)
