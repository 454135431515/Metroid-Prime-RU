Metroid Prime: русский перевод

Сборка мода для порта MetroidPrimePort прямо в браузере — на телефоне или компьютере. Образ не покидает устройство: всё считается здесь, ничего не загружается на сервер.

1. Выберите свой образ Metroid Prime USA 1.00 (GM8E01, ревизия 0) в формате ISO.

3. Сохранить архив 

  


  

    
Установка

    
    
      
  1. Распакуйте архив: внутри две папки, russian и hud-russian. Нужны обе.
    2. 
      
  2. Положите их в папку mods порта:
        
      
          
    • Android: /storage/emulated/0/MetroidPrime/mods (сначала в порте F1 → System →
            Data folder → общая память);
      • 
          
    • Windows: user\mods рядом с metroid_prime_port.exe;
      • 
          
    • Linux: mods рядом с файлом .AppImage.
      • 
        
    3. 
      
  3. Язык текста в настройках порта оставьте английским и перезапустите игру.
    4.
